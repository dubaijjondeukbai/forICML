ICML 2027
2027년 부터는 투고 시 논문의 핵심 기여에 해당하는 유형 하나를 선택해야 함
Contribution Type                 논문의 핵심 기여                              주의 사항
General                         새로운 알고리즘, 방법, 실증적 발견  
Theory                          수학적 이론, 증명, 이론적 분석
Application-driven              실제 문제에서 도출된 새로운 ML 접근            기존 모델을 새로운 데이터셋에 적용하는 것만으로는 일반적으로 충분하지 않음
Concept and Feasibility         파급력 있는 새로운 개념과 실현 가능성           예비 실험만 수행한 미완성 연구를 위한 유형이 아님
Negative Results                중요한 실패 현상이나 기존 가정의 한계 규명      단순히 실험이 실패했다는 사실만으로는 충분하지 않음
Datasets,                       새로운 데이터,
Evaluations and Benchmarks      평가 방법, 벤치마크
>>Contribution Type별로 채택 인원이 따로 배정되지 않음

2027년 주요 변경 사항
변경 사항                 공식 내용                                          
Two-stage Reviewing       1차에서 경쟁력이 명백히 부족한 논문을 조기 탈락
Contribution Type         6가지 핵심 유형 중에서 하나 선택
AI Diclosure              실질적인 생성형 AI 사용 공개 의무화
Reciprocal Reviewing      적격 공동저자의 리뷰 참여 요구 또는 제한적 예외
Submission Quota          저자별 투고 건수 최대 20편까지 공동 저자로 제한
PC참여                     3편 이상 논문에 저자로 참여한 연구자는 반드시 위원회 활동을 수행
페이지 제한                8페이지 제한 적용되고, 최종본은 1페이지 추가 허용, 초과 시 desk reject
